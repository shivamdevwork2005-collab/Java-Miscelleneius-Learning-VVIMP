## ▶️ How to Run

**1. Clone the repository**

```bash
git clone https://github.com/shivamdevwork2005-collab/Core-Java.git
```

**2. Navigate to the directory**

```bash
cd Core-Java
```

**3. Compile the program**

```bash
javac Main.java
```

**4. Execute the program**

```bash
java Main
```
